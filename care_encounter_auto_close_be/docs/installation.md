# Installation

## Stable release

To install Care Encounter Auto Close Plugin, run this command in your terminal:

```sh
pip install Care Encounter Auto Close Plugin
```

## From source

The source files for Care Encounter Auto Close Plugin can be downloaded from the [Github repo](https://github.com/ohcnetwork/care_encounter_auto_close_be).

You can either clone the public repository:

```sh
git clone git://github.com/ohcnetwork/care_encounter_auto_close_be
```

Or download the [tarball](https://github.com/ohcnetwork/care_encounter_auto_close_be/tarball/master):

```sh
curl -OJL https://github.com/ohcnetwork/care_encounter_auto_close_be/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd care_encounter_auto_close_be
pip install .
```
